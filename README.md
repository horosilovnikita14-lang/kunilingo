# KuniLingo

Учебное приложение для подготовки к ЕГЭ по русскому языку: последовательный Путь, практика по банку заданий и рисованная анимированная комната для занятий.

Это актуальные исходники локальной разработки на 9 ноября 2026 года. Загрузка исходников в GitHub не обновляет опубликованный сайт.

- [Обязательная дизайн-система](DESIGN_SYSTEM.md): сохранять согласованное оформление и поведение при доработках.

## Запуск

Нужен Node.js 24, версия не ниже 24.5, и npm.

```sh
npm ci
npm run build
npm run dev
```

Откройте [локальную Практику](http://127.0.0.1:4197/?ui=59&style=copper#/russian/practice) или [Путь](http://127.0.0.1:4197/?ui=59&style=copper#/russian/path).

Сервер слушает только `127.0.0.1:4197`. Другой порт можно задать переменной `PORT`. Клиент читается непосредственно из `app/`: после правок достаточно обновить страницу. Логика банка читается из `dist/server/index.js`, аккаунты и обращения — из `scripts/beta102-api.mjs`; после изменения сервера нужен перезапуск, после изменения банка также повторная сборка.

Для просмотра компонентов откройте [служебную галерею](http://127.0.0.1:4197/design102.html). Она использует настоящие карточки, контролы, справочники и карандаш с изолированными примерами. Аккаунты и данные учеников в галерею не загружаются.

## Первый локальный аккаунт

Нажмите «Войти» → «Создать аккаунт». Нужны логин и пароль; почта не требуется. Первый зарегистрированный аккаунт становится владельцем локальной беты и видит очередь всех обращений. Последующие аккаунты видят только свои учебные данные и сообщения. Тестовые аккаунты автоматически не создаются.

Пользователи, серверные сессии, прогресс и обращения хранятся в `.local-data/beta102.sqlite`. Папка закрыта от HTTP и исключена из Git. Перезапуск сервера сохраняет данные. Для резервной копии остановите сервер и скопируйте всю `.local-data/`; не передавайте эту папку вместе с исходниками дизайнеру.

Гостевая работа остаётся в браузере. После входа приложение предлагает явно выбрать работу аккаунта или перенести гостевую копию. Перенос заменяет текущую копию аккаунта; исходная гостевая работа сохраняется. После выхода восстанавливается гостевая копия. При конфликте двух устройств приложение сохраняет обе версии до выбора пользователя. Неотправленная работа хранится отдельно для каждого аккаунта и повторно отправляется при следующей записи, восстановлении сети, повторном входе или нажатии «Сохранить сейчас».

Вход и выход используют серверные cookie-сессии; пароли хранятся как salted scrypt-хеши. Запросы учебных данных привязаны к отображаемому аккаунту, поэтому смена входа в соседней вкладке не записывает работу одному ученику от имени другого.

## Проверки

```sh
npm run build
npm test
```

Для проверки тематического покрытия всего банка: `npm run topics:audit`. Команда `npm run topics:prepare` дополнительно готовит локальную очередь с очищенными условиями в `work/topic-classification101.jsonl`. Эти команды не обращаются к модельному API и ничего не отправляют наружу. Сборка также сохраняет отчёт в `dist/reports/topic-coverage101.json`.

Тесты проверяют выдачу всех 2795 условий без внешнего соединения, сохранение ключей на сервере, проверку ответов, сессии ФИПИ, редактор пометок, привязку справочников, аккаунты, сохранение SQLite после перезапуска, изоляцию двух учеников, конфликты, обращения и весь сквозной сценарий оболочки. Проверки DOM выполняются с `happy-dom`; они не заменяют визуальный просмотр в браузере.

## Состояние функций

- Практика: 2795 заданий — 2140 открытого банка и 655 архивных. Фильтры по разделу, типу, теме, году и поиску.
- Свободный карандаш, ластик, отмена и повтор действия, пять цветов и три толщины. Пометки и черновики сохраняются в браузере.
- Справочники №16: 15 общих тем и 54 разобранных примера. Справочники по обособлению (№17): 9 категорий и 55 авторских примеров; проверены по ФИПИ и академическим правилам 9 ноября 2026 года.
- Практика выбирает только статьи категорий конкретной карточки. Для №17 старые эвристические теги остаются кандидатами: контекстные статьи подключаются только к проверенным привязкам. Сейчас это одна из 117 карточек №17; остальные 116 включены в очередь проверки. Полный справочник номера и соседние темы автоматически не добавляются.
- Общие статьи используются и в Пути: №16 в двух уроках, обособление в уроках «Определения и приложения», «Обособленное приложение и слово КАК», «Обстоятельства и уточнения». При возврате из задания восстанавливается каталог.
- 100 карточек относятся к №16 после проверки прежней группы из 105 записей; пять ошибочно отнесённых карточек перенесены по проверяемому навыку.
- Подготовка банка автоматически переиспользует существующие категории, отделяет проверенные назначения от кандидатов, показывает пробелы теории и группирует точные повторы очереди. Отпечатки учитывают условие, исходный текст и версию дерева. Ответы, GUID и служебные поля в очередь не включаются. Старый поиск по словам больше не назначает новые теги для №16 и №17.
- Аккаунты: регистрация, вход, выход, сохранение Пути, ответов, черновиков и пометок, явный перенос гостевой работы и разрешение конфликтов. «Прогресс» показывает реальные результаты текущего ученика.
- Обратная связь доступна во всех разделах: категория проблемы, описание и контекст текущего задания/урока. Черновик сообщения сохраняется до успешной отправки отдельно по аккаунту и контексту. Владелец видит очередь и меняет статусы «Новое», «В работе», «Исправлено»; ученик видит статусы своих обращений.
- Для всех 365 конечных категорий создан единый контентный контракт. 23 категории содержат полные статьи, 342 имеют честный статус черновика. Пакет содержания можно выгрузить, проверить и посмотреть в галерее без изменения работающего приложения.
- Сам смысловой классификатор и полные материалы остальных категорий пока не подключены. Это оставшаяся содержательная работа; готовая техническая основа не означает, что весь курс уже предметно вычитан.

## Структура

| Путь | Назначение |
| --- | --- |
| `app/` | Клиент, оформление, учебные модули и визуальные ресурсы |
| `server-source/` | Снимки заданий, серверная проверка и тематическая разметка |
| `build.mjs` | Сборка клиента и серверного Worker в `dist/` |
| `worker-routing.js`, `worker-transport.js` | Маршрутизация, кэширование и соединение с ФИПИ |
| `scripts/preview98.mjs` | Локальный Node-сервер |
| `app/study101-registry.js` | Общий реестр категорий и статей для Практики и Пути |
| `app/study102-content.js`, `app/design102.*` | Контракт всего содержания, JSON-предпросмотр и галерея компонентов |
| `app/beta102-*`, `app/progress102.*` | Аккаунт, синхронизация, сообщения и реальные результаты |
| `scripts/beta102-api.mjs` | Локальный API аккаунтов, прогресса и поддержки |
| `server-source/topic-preparation101.mjs`, `scripts/topics101.mjs` | Покрытие банка и подготовка очереди классификации |
| `scripts/fipi-intermediate.pem` | Публичный промежуточный сертификат для проверки цепочки TLS ФИПИ |
| `*.test.mjs` | Самодостаточные автоматические проверки |

`dist/` и `node_modules/` восстанавливаются командами выше и не хранятся в Git. Привязки старого хостинга, `.env`, журналы и пользовательские данные в репозиторий не входят. Сборка работает без `.openai/hosting.json`.

Условия, архивные ответы и исходная разметка находятся на серверной стороне. В клиентские файлы и ответы API условий ключи не добавляются. Личные данные SQLite и браузерное хранилище не являются частью репозитория.

## Источники и ограничения

Учебные задания происходят из [открытого банка ФИПИ](https://ege.fipi.ru/bank/) и [официальных демоверсий](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory). Их авторство не приписывается KuniLingo. Справочные объяснения сверяются с [навигатором ФИПИ](https://fipi.ru/navigator-podgotovki/navigator-ege) и нормативными источниками; ссылки сохранены у соответствующих тем. На дату последней проверки материалы 2027 года обозначены ФИПИ как проекты.

Все условия доступны из локального снимка. Автоматическая проверка части кратких банковских ответов зависит от внешнего ФИПИ. В прежнем окружении Vercel наблюдался таймаут соединения; этот репозиторий не означает, что ограничение устранено. Сочинения автоматически не оцениваются.

Локальный адаптер сохраняет стандартную проверку сертификата и имени сервера, добавляя только публичный промежуточный сертификат. Отключать TLS-проверку для запуска не требуется.

Настройки опубликованного Vercel-проекта сюда не перенесены. Для размещения в другом окружении потребуется отдельная настройка сервера и хостинга.
