# KuniLingo

Учебное приложение для подготовки к ЕГЭ по русскому языку: последовательный Путь, практика по банку заданий и рисованная анимированная комната для занятий.

Это актуальные исходники локальной разработки на 9 ноября 2026 года. Загрузка исходников в GitHub не обновляет опубликованный сайт.

## Документация для разработчика

- [Правила работы с проектом](AGENTS.md).
- [Обязательная дизайн-система](DESIGN_SYSTEM.md): сохранять согласованное оформление и поведение при доработках.
- [Автоматическая разметка и подбор теории](docs/automatic-topics.md): проект дальнейшей архитектуры. Подбор статей по готовым категориям работает; массовый смысловой классификатор ещё не реализован.

## Запуск

Нужен Node.js 24, версия не ниже 24.5, и npm.

```sh
npm ci
npm run build
npm run dev
```

Откройте [локальную Практику](http://127.0.0.1:4197/?ui=59&style=copper#/russian/practice) или [Путь](http://127.0.0.1:4197/?ui=59&style=copper#/russian/path).

Сервер слушает только `127.0.0.1:4197`. Другой порт можно задать переменной `PORT`. Клиент читается непосредственно из `app/`: после правок достаточно обновить страницу. Серверная логика читается из `dist/server/index.js`: после её изменения нужно повторить сборку и перезапустить сервер.

## Проверки

```sh
npm run build
npm test
```

Тесты проверяют выдачу всех 2795 условий без внешнего соединения, сохранение ключей на сервере, проверку ответов, сессии ФИПИ, редактор пометок, привязку справочников и целостность тематических данных. Проверки DOM выполняются с `happy-dom`; они не заменяют визуальный просмотр в браузере.

## Состояние функций

- Практика: 2795 заданий — 2140 открытого банка и 655 архивных. Фильтры по разделу, типу, теме, году и поиску.
- Свободный карандаш, ластик, отмена и повтор действия, пять цветов и три толщины. Пометки и черновики сохраняются в браузере.
- Справочники пока реализованы для №16: 15 общих тем и 54 разобранных примера. Практика автоматически выбирает статьи по категориям конкретной карточки. Полный справочник номера и соседние темы автоматически не добавляются.
- Те же материалы доступны в двух соответствующих уроках Пути. При возврате из задания восстанавливается каталог.
- 100 карточек относятся к №16 после проверки прежней группы из 105 записей; пять ошибочно отнесённых карточек перенесены по проверяемому навыку.
- Массовый смысловой классификатор новых заданий, остальные справочники, аккаунты и обратная связь ещё не реализованы. Раздел «Прогресс» требует дальнейшей работы.

## Структура

| Путь | Назначение |
| --- | --- |
| `app/` | Клиент, оформление, учебные модули и визуальные ресурсы |
| `server-source/` | Снимки заданий, серверная проверка и тематическая разметка |
| `build.mjs` | Сборка клиента и серверного Worker в `dist/` |
| `worker-routing.js`, `worker-transport.js` | Маршрутизация, кэширование и соединение с ФИПИ |
| `scripts/preview98.mjs` | Локальный Node-сервер |
| `scripts/fipi-intermediate.pem` | Публичный промежуточный сертификат для проверки цепочки TLS ФИПИ |
| `*.test.mjs` | Самодостаточные автоматические проверки |

`dist/` и `node_modules/` восстанавливаются командами выше и не хранятся в Git. Привязки старого хостинга, `.env`, журналы и пользовательские данные в репозиторий не входят. Сборка работает без `.openai/hosting.json`.

Условия, архивные ответы и исходная разметка находятся на серверной стороне. В клиентские файлы и ответы API условий ключи не добавляются. Прогресс, ответы пользователя и рисунки из `localStorage` не являются частью репозитория.

## Источники и ограничения

Учебные задания происходят из [открытого банка ФИПИ](https://ege.fipi.ru/bank/) и [официальных демоверсий](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory). Их авторство не приписывается KuniLingo. Справочные объяснения сверяются с [навигатором ФИПИ](https://fipi.ru/navigator-podgotovki/navigator-ege) и нормативными источниками; ссылки сохранены у соответствующих тем. На дату последней проверки материалы 2027 года обозначены ФИПИ как проекты.

Все условия доступны из локального снимка. Автоматическая проверка части кратких банковских ответов зависит от внешнего ФИПИ. В прежнем окружении Vercel наблюдался таймаут соединения; этот репозиторий не означает, что ограничение устранено. Сочинения автоматически не оцениваются.

Локальный адаптер сохраняет стандартную проверку сертификата и имени сервера, добавляя только публичный промежуточный сертификат. Отключать TLS-проверку для запуска не требуется.

Настройки опубликованного Vercel-проекта сюда не перенесены. Для размещения в другом окружении потребуется отдельная настройка сервера и хостинга.
